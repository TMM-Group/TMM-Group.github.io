加入我们2025-06-17

长期招聘本科生、研究生、博士后

1. 本科生
课题组热烈欢迎对科研感兴趣、学有余力的力学、物理、材料等专业的学生加入（大一到大四的学生都欢迎）。课题组老师和研究生将带你领略科研的魅力，感受知识的力量: 从原子尺度拍“自拍照”到乐高积木搭原子力显微镜，从C/Fortran/Python代码到机器学习到超级计算机，从原子尺度新奇性质到材料超常规性能私人定制，从薛定谔方程到材料基因数据库等等，总有一款适合你！
加入课题组后，可以使用课题组资源，如通过培训后使用课题组各种实验仪器设备，开通超算账号使用服务器和超算资源，课题组内部的资源和文件共享平台等，还可自主选择参加课题组每周的组会，每个月一次的Journal Club (全英文报告和讨论)，以及每周固定时间的文体活动(本年度是羽毛球)，聚餐和其他团建活动。
感兴趣的同学请直接发email到本页面最下方联系人邮箱。
2. 研究生
北京理工大学先进材料力学实验室热烈欢迎热爱科研、勤奋努力并有团队合作精神的学生加入。欢迎力学、物理、材料等专业的本科生申请直博/直硕，对微纳力学、多物理场耦合力学、力学超材料、功能材料和能源材料感兴趣的硕士生（理论与实验均可），欢迎报考申请考核制博士生。
感兴趣的同学请直接发email到本页面最下方联系人邮箱。
3. 博士后（长期有效）
招聘要求：
1. 具有力学、物理、材料或相关专业的博士学位（或近期将获得博士学位）；
2. 具有独立开展科研的能力、扎实的专业积累、良好的职业操守以及团队合作精神；
3. 符合北京理工大学博士后招收的基本条件；
4. 将优先考虑如有以下研究背景之一的申请者：
1）第一性原理计算方法，相场方法，或者多场耦合的有限元模拟；
2）中子散射或同步辐射实验技术；
3）压电、铁电、多铁等铁性材料，热电材料的制备和表征；
4）压电力显微镜等相关扫描探针技术；
5）微纳米力学，计算力学，电子封装力学。
博士后待遇：
1. 30-50万基本年薪+科研奖励+学校缴纳的社保、公积金，上不封顶；
2. 入选学校“特立博士后”支持计划者，实施贯通式培养，出站可聘为预聘制教师；
3. 如果入选“博新计划”、“国际交流计划”引进项目，薪酬最高可到70万+；
4. 留京工作的博士后可以解决本人、配偶、子女在京落户；
5. 学校提供博士后公寓或租房补贴；
6.未成年子女可进入拥有优质教育资源的理工附小、附幼就读，免去家庭后顾之忧。
4. 预聘制教职（长期有效）   
岗位待遇：
1. 预聘助理教授，年薪30万，另加五险一金，科研启动经费40万，直接聘为硕导，可竞聘博导;
2. 预聘副教授：年薪36万，另加五险一金，科研启动经费60万，直接聘为博导;
3. 学校提供公寓或租房补贴；
4. 未成年子女可进入拥有优质教育资源的理工附小、附幼就读，免去家庭后顾之忧。
博士后/预聘制教职应聘流程和材料：
申请人将申请材料发送到下列联系人邮箱，邮件标题请注明“姓名 + 博士后/预聘助理教授/预聘副教授 + 应聘”。
申请材料需包括：
(1) 详细的个人简历，含学习、工作和科研的经历，主要科研成果（如论文论著、成果证书或奖励）清单；

(2) 其他可以证明工作能力的材料。
